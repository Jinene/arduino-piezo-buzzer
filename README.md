# 🔔 Arduino Piezo Buzzer Project

A simple Arduino project demonstrating how to use a piezo buzzer.

## 📌 Features
- Simple ON/OFF beep
- Tone generation using frequency
- Simple melody example

## 🛠 Hardware Required
- Arduino (Uno, Nano, etc.)
- Piezo buzzer (active or passive)
- Jumper wires

## 🔌 Wiring
Buzzer +  → Pin 8  
Buzzer –  → GND  

## 🚀 How to Use
1. Open `piezo_buzzer.ino` in Arduino IDE.
2. Select your board and COM port.
3. Upload the code.
4. Enjoy the sound 🎵

## 📚 Concepts Covered
- Digital Output
- tone() function
- PWM basics
